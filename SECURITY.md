# Security Policy

## Supported versions

While **Capital** is pre-1.0, only the latest release on `main` receives
security fixes. Update the table below once we start maintaining multiple
release lines.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| older   | :x:                |

## Reporting a vulnerability

**Please do not open a public issue for security vulnerabilities.**

Instead, report it privately via one of:

- GitHub's [private vulnerability reporting](https://github.com/FurkanEdizkan/Capital/security/advisories/new)
  (preferred — enable it under **Settings → Security → Advisories**), or
- Email **furkandedizkan@gmail.com**.

Please include:

- A description of the vulnerability and its impact.
- Steps to reproduce, or a proof-of-concept.
- Affected version(s) / commit, and your environment.

## What to expect

- We aim to acknowledge a report within **72 hours**.
- We'll keep you informed of progress and credit you in the advisory unless you
  prefer to remain anonymous.
- Please give us a reasonable window to ship a fix before any public
  disclosure.
